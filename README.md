# MineScape Resource Pack

Resource pack for the MineScape Minecraft server: https://minescape.com

**Documentation updated:** 13 November 2026  
**Project:** MineScape / Old School RuneScape-inspired Minecraft resource pack

## Contents

The pack contains textures, models, animations, sounds and other Minecraft resources. The files can change as MineScape develops.

- `pack.mcmeta` — Minecraft resource-pack metadata, format compatibility and overlays.
- `pack.png` — resource-pack icon (not included in this documentation-only update).
- `credit.txt` — project history, attribution, rights and usage information.
- `LICENSE` — unmodified GNU General Public License, version 3 (29 June 2007).
